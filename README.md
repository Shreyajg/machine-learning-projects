# Machine Learning Projects

A collection of Machine Learning and Deep Learning projects implemented as part of my learning journey in Artificial Intelligence and Data Science. This repository contains projects covering regression, classification, computer vision, and practical machine learning workflows.

## Repository Structure

### AQI Prediction

Air Quality Index prediction using machine learning techniques.

**Topics Covered**

* Data preprocessing
* Feature selection
* Regression models
* Model evaluation

### Housing Price Prediction

Predicting housing prices using regression algorithms.

**Topics Covered**

* Exploratory Data Analysis (EDA)
* Feature engineering
* Linear Regression
* Performance metrics

### Titanic Survival Prediction

Classification project based on the Titanic dataset.

**Topics Covered**

* Data cleaning
* Handling missing values
* Feature encoding
* Classification algorithms
* Accuracy evaluation

### Superconductivity Prediction

Predicting critical temperatures of superconducting materials using machine learning.

**Topics Covered**

* High-dimensional datasets
* Feature reduction
* Regression techniques
* Model comparison

### Linear Regression From Scratch

Implementation of Linear Regression without using machine learning libraries.

**Topics Covered**

* Gradient Descent
* Cost Function Optimization
* Mathematical foundations of machine learning

### Cat vs Dog Image Classification

Deep Learning project for binary image classification.

**Topics Covered**

* Convolutional Neural Networks (CNNs)
* Image preprocessing
* Model training and validation
* Deep learning fundamentals
